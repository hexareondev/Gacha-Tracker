## Зачем это

Если вы играете в гачи от HoYoverse, то наверняка хоть раз задавались вопросами: сколько примогемов ещё можно выбить из достижений? Сколько круток в среднем уходит на пятизвёздочного? Как часто я выигрываю 50/50? Хватит ли нефрита к следующему баннеру?

Гача Трекер собирает ответы в одном месте. Это обычная веб-страница: открыли — пользуетесь. Ничего не нужно устанавливать, не нужен аккаунт, и никто, кроме вас, не видит ваших данных.

Меню разбито по играм — у каждой свой набор разделов:

| | Genshin Impact | Honkai: Star Rail | Zenless Zone Zero | Другие игры |
|:--|:--:|:--:|:--:|:--:|
| 💎 **Крутки** — запасы валюты по патчам | ✓ | ✓ | ✓ | ✓ |
| 🎯 **Шансы** — хватит ли на персонажа | ✓ | ✓ | ✓ | |
| 🎲 **История** — гаранты, 50/50 и оценка удачи | ✓ | ✓ | ✓ | |
| 🏆 **Достижения** — полный список с наградами | ✓ | ✓ | ✓ | |
| 📅 **Календарь** — ежедневные награды | | | ✓ | |

Для любой другой гачи можно создать свой профиль прямо в меню: в нём доступен калькулятор круток. Остальным разделам нужны данные, которые трекер умеет разбирать только для трёх игр HoYoverse.

## 🎲 История круток

Загрузите файл истории в формате **UIGF v4** — его умеют делать популярные выгрузчики, например [stardb.gg](https://stardb.gg).

- Перед загрузкой видно, что именно добавится, — ничего не перезапишется без вашего ведома.
- Можно загружать файлы из разных источников: они дополнят друг друга без дублей.
- Для каждого баннера: текущий гарант, сколько круток ушло на каждое ценное выпадение, среднее значение.
- Поддерживаются все каналы, включая коллаборации Star Rail и «повторный показ» агентов и амплификаторов в Zenless Zone Zero.
- Один файл может содержать несколько игр — записи сами разложатся по своим разделам.
- **Статистика 50/50:** выигрыши, проигрыши и гаранты; разметку можно поправить вручную.
- **Оценка удачи:** насколько ваше среднее число круток на топовое лучше или хуже ожидаемого — и удачливее какой доли игроков вы оказались. То же для 50/50.
- **Распределение по гаранту:** на какой крутке у вас выпадали топовые — рядом с тем, как это должно выглядеть по механике игры.
- Портреты выпавших персонажей и оружия, таблицей или сеткой.
- В Chrome и Edge страница может запомнить файл выгрузки и сама перечитывать его при каждом открытии.

## 🎯 Хватит ли на персонажа

В разделе «Крутки» трекер берёт ваш запас круток, а из истории — сколько круток прошло с последнего топового и есть ли гарант после проигранного 50/50. По этим данным он считает:

- шанс получить персонажа (или оружие) с тем, что уже накоплено;
- шансы на каждую копию — вплоть до C6, E6 или M6;
- сколько круток нужно на 50% и 90% шанса и сколько — чтобы получить наверняка.

Учитываются мягкий и жёсткий гарант, 50/50 у персонажей и 75/25 у оружия. Гарант и запас можно поправить вручную. Расчёт идёт только от того, что у вас уже есть, без прогнозов будущих наград.

## 💎 Крутки и 📅 Календарь

**Крутки** — простой учёт валюты по патчам: сколько было в начале патча, сколько стало к концу и во сколько круток это выливается. Для Genshin и Star Rail валюта уже заведена, для своих игр — настраивается под любую систему круток.

**Календарь** — для ежедневных наград в Zenless Zone Zero. Отмечайте, что выпало за день, и смотрите итоги за месяц и год, графики и самые удачные дни. День переключается по времени выбранного сервера, а не в полночь.

## 🔒 Где хранятся данные

**Только в вашем браузере.** У трекера нет сервера: всё, что вы отмечаете и загружаете, остаётся на вашем устройстве. Файлы истории круток читаются локально и никуда не отправляются.

Чтобы перенести данные на другое устройство или подстраховаться, откройте меню **···** и выберите **«Скачать резервную копию»**. Один файл сохранит всё: календарь, крутки, историю и прогресс достижений.

**Синхронизация между устройствами** — по желанию. В **Настройках** можно указать токен GitHub с правом `gist`: копия данных будет храниться в секретном gist вашего собственного аккаунта, и её можно загрузить на другом устройстве. Изменения отправляются сами раз в 5 минут, а если копию тем временем обновило другое устройство, трекер не перезапишет её и предложит сначала загрузить. Токен остаётся только в вашем браузере. У каждого, кто пользуется сайтом, — свой аккаунт и своя копия.

> [!WARNING]
> Если очистить данные браузера, записи пропадут. Время от времени сохраняйте резервную копию или отправляйте её в GitHub.

## ❓ Частые вопросы

<details>
<summary><b>Нужно ли вводить логин или пароль от игры?</b></summary>
<br>
Нет. Трекер не подключается к аккаунту и не просит никаких данных для входа. Историю круток вы загружаете сами — файлом, сделанным сторонним выгрузчиком.
</details>

<details>
<summary><b>Откуда берётся список достижений?</b></summary>
<br>
Из открытой базы <a href="https://stardb.gg">stardb.gg</a>. Раз в неделю её автоматически скачивает скрипт в GitHub Actions, поэтому достижения из новых патчей появляются без участия человека.
</details>

<details>
<summary><b>Почему подсказки к достижениям на английском?</b></summary>
<br>
Так их публикует stardb.gg: названия и описания там переведены, а подсказки сообщества — нет.
</details>

<details>
<summary><b>Работает ли на телефоне?</b></summary>
<br>
Да, страница адаптирована под мобильные экраны. Игры и их разделы открываются через меню ≡ в левом верхнем углу.
</details>

<details>
<summary><b>Можно ли установить как приложение?</b></summary>
<br>
Да. В Chrome и Edge — пункт <b>«Установить как приложение»</b> в меню <b>···</b> трекера (или значок установки в адресной строке). На iPhone — <b>Поделиться → На экран «Домой»</b> в Safari. Установленный трекер открывается отдельным окном и работает без интернета.
</details>

<details>
<summary><b>Это официальный проект HoYoverse?</b></summary>
<br>
Нет, это неофициальный фанатский проект.
</details>

## 🛠 Свой экземпляр

Хотите собственную копию — например, чтобы что-то в ней поменять?

1. Нажмите **Fork** вверху страницы репозитория.
2. В своей копии: **Settings → Pages**, источник — ветка `main`, папка `/ (root)`.
3. **Actions** → включите workflows и один раз запустите **«Обновление базы достижений»** кнопкой **Run workflow**.

Через минуту сайт будет доступен по адресу `https://<ваш-ник>.github.io/<имя-репозитория>/`, а базы достижений начнут обновляться каждую среду.

<details>
<summary><b>Как устроен проект</b></summary>
<br>

Трекер написан на чистом HTML, CSS и JavaScript, без фреймворков и сборки: файлы отдаются как есть, каждый раздел — отдельный скрипт. Данные хранятся в `localStorage` и `IndexedDB`, офлайн-работу обеспечивает service worker.

Базы достижений собирает Python-скрипт (только стандартная библиотека, Python 3.8+). Сайт читает их напрямую из репозитория, поэтому новые данные видны сразу после коммита.

```mermaid
flowchart LR
    A["⏰ GitHub Actions<br/>каждую среду"] --> B["🐍 fetch_achievements.py"]
    C["stardb.gg"] --> B
    B --> D["📁 achievements/data/*.json"]
    D --> E["🌐 Гача Трекер"]
    E --> F["💾 копия в браузере"]
```

```
├── index.html                          # разметка страницы
├── css/style.css                       # оформление
├── js/
│   ├── core.js                         # хранилище и общие утилиты
│   ├── calendar.js                     # календарь ежедневных наград
│   ├── history.js                      # история круток, портреты, удача
│   ├── backup.js                       # резервные копии
│   ├── settings.js                     # настройки и меню
│   ├── pulls.js                        # крутки и патчи
│   ├── achievements.js                 # достижения и поиск
│   ├── odds.js                         # модель гаранта и шансы
│   ├── sync.js                         # синхронизация и установка
│   └── nav.js                          # меню игр и запуск
├── sw.js                               # работа без интернета
├── manifest.webmanifest                # описание приложения
├── icons/                              # значки приложения
├── favicon.svg
├── achievements/
│   ├── fetch_achievements.py           # сборщик баз достижений
│   └── data/                           # базы по играм
└── .github/workflows/
    └── update-achievements.yml         # еженедельное обновление
```

Запустить сборщик вручную:

```bash
python achievements/fetch_achievements.py --out achievements/data --lang ru
```

Параметры: `--games gi,hsr,zzz` — какие игры, `--lang` — язык (`ru`, `en`, `ja`…), `--source auto|stardb|fallback` — откуда брать данные.

Скрипты подключаются по порядку и делят общую область видимости, поэтому порядок `<script>` в `index.html` важен.

Если открыть `index.html` прямо с диска, всё, кроме достижений и офлайн-режима, работает сразу. Для достижений запустите локальный сервер (`python -m http.server`) или загрузите файл базы кнопкой **«Загрузить файл»**.

</details>
